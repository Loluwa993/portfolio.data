Technical Walkthrough & Code Implementation

The core computational routine handles data inputs, applies business rules, and outputs verified calculations directly to the console or visual dashboard:

#BMI = (weight in pounds x 703) / (height in inches x height in inches)

# --- Execution & Logic Steps ---

#Taking input from user
name = input("Enter your name: ")
weight = int(input("Enter your weight in pounds: "))

height = int(input("Enter your height in inches: "))

#calculating BMI
BMI = (weight * 703) / (height **2)
print('BMI is: ',BMI)

#information on BMI ranges
#Under 18.5	Underweight	Minimal
#18.5 - 24.9	Normal Weight	Minimal
#25 - 29.9	Overweight	Increased
#30 - 34.9	Obese	High
#35 - 39.9	Severely Obese	Very High
#40 and over	Morbidly Obese	Extremely High


#presenting the user the review of the calculated BMI
if BMI > 0:
    if (BMI<18.5):
        print(name + ", You are Underweight")
    elif (BMI<=24.9):
        print(name + ", You are Normal weight.")
    elif (BMI<=29.9):
        print(name + ", You are Overweight.")
    elif (BMI<=34.9):
        print(name + ", You are Obese High.")
    elif (BMI<=39.9):
        print(name + ", You are Severely Obese Very High.")
    else:
        print(name + ", You are Morbidly Obese Extremely High.")

# --- Execution & Logic Steps ---

#printing received values for confirmation
print(name)
print (weight,'lbs')
print (height, 'in')
